## Memory (one plan + one execute in a fresh process; sizes in KiB)

heap = bytes live in malloc-family allocations above the user's input/output buffers, peak over plan+execute (link-time malloc interposer, malloc_usable_size; excludes thread stacks and static data). RSS = ru_maxrss (peak resident set) of the whole process minus the same measurement for a do-nothing benchee at the same size (removes the input/output buffers and process baseline; includes library code pages touched, static tables and thread stacks).
